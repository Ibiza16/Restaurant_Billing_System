# Restaurant_Billing_System


**Project Description**

This Restaurant Billing System is a Python-based desktop application designed to streamline the order processing and billing operations in a restaurant. It allows users to input quantities for various menu items, calculates the total cost including taxes and service charges, and generates a detailed receipt.

**Key Features**

**Itemized Billing**: Supports a variety of food items, cakes, and drinks with individual quantity inputs.  
**Automatic Calculations**: Calculates costs, taxes, service charges, subtotal, and the final total automatically.   
**Receipt Generation**: Displays the receipt in the app’s GUI and allows users to generate and save a professional PDF receipt.   
**Unique Receipt Reference**: Each transaction is assigned a unique receipt number for easy tracking.   
**Printable PDF Receipt**: The PDF includes all order details, costs, and a friendly thank you message for customers.   
**Simple and User-Friendly Interface**: Designed with Tkinter for ease of use in real-time order processing.

**Technologies Used**

Python 3.x
Tkinter (for GUI)   
ReportLab (for PDF generation)   
Random module (for receipt reference generation)
